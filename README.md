# Bullpen

Learn investing in short lessons, then compete in a paper-trading season ranked on skill.

- `prototype/index.html`: the clickable demo. Open it in any browser.
- `CLAUDE.md`: the project brief. Claude Code reads it automatically.
- `docs/review-brief.md`: the first prompt to give Claude Code.
- `docs/ROADMAP.md`: where we are and what's next.
- `docs/how-we-work.md`: how we both work on this repo.

## Getting it into Claude Code
1. Make a new GitHub repo (for example `bullpen`), private.
2. Upload or push this folder to it.
3. Open the repo in Claude Code (desktop app, web, or `claude` in a terminal inside the folder).
4. Paste the prompt from `docs/review-brief.md`.
